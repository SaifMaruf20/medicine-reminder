> **Owsud Sathi** (অসুধ সাথী) is a comprehensive digital pharmacy, medicine delivery, and healthcare management platform ecosystem. Integrates admin portal controls, RESTful APIs, consumer landing platforms, and mobile application interfaces.

---

## 🎯 Architecture & Subsystems

- 📱 **`mobile_app/`**: Mobile app UI & application code for healthcare customers.
- 💻 **`admin/`**: Admin portal dashboard for managing inventory, pharmacy orders, and prescriptions.
- 🔌 **`api/`**: Server-side REST API services handling authentication, order processing, and medicine databases.
- 🌐 **`landing/`**: High-converting web landing platform for user onboarding and product discovery.
- 📜 **`scripts/`**: Automation tools and database deployment helpers.
